# Отчёт по проверке Smart Support Hub

Дата: 10 ноября 2026 г.  
Публичная версия: https://onepersic.github.io/smart-support-hub/

## Проверки

| Сценарий | Результат | Примечание |
|---|---|---|
| Публичная страница GitHub Pages | Пройдено | Страница и разделы открываются по публичной ссылке. |
| Пустая форма инцидента | Пройдено | Браузер не позволяет отправить обязательное пустое описание. |
| Создание и изменение инцидента | Пройдено | Новая запись появилась в таблице; перевод в «Решена» обновил SLA и число открытых обращений. |
| Фильтр инцидентов | Пройдено | Фильтр «Решённые» показывает завершённые записи. |
| Сохранение данных после перезагрузки | Пройдено | Созданная тестовая запись осталась в localStorage этого браузера. |
| Создание заявки и график | Пройдено | Заявка отобразилась в таблице и изменила диаграмму типов заявок. |
| Переключение темы | Пройдено | Светлая тема включилась и сохранилась после перезагрузки. |
| Мобильная ширина 390 px | Исправлено в v1.1.0 | Фильтр и кнопка сохранения расположены вертикально; кнопка занимает всю ширину формы; таблица прокручивается горизонтально. |
| Планшетная ширина 768 px | Исправлено в v1.1.0 | Легенда диаграммы размещается под графиком, подписи доступны целиком. |
| Расчёт следующей версии | Пройдено | Для уровня minor предложена следующая минорная версия. |

## Замечания и ограничения

Проверки выполнялись вручную в браузере. Тестовые записи сохраняются только в локальном хранилище проверявшего браузера и не синхронизируются между посетителями. Консоль разработчика отдельно не проверялась. Два GitHub Issue созданы по результатам внутренней проверки интерфейса; это не отзывы одногруппников. Для выполнения требования об отзывах нужно получить два замечания от реальных пользователей.

## Вывод

Основные сценарии панели работают: формы проверяют обязательные поля, статусы и фильтр обновляют список, SLA пересчитывается, графики отражают данные, а настройки сохраняются в браузере. Найденные проблемы отображения для планшетной и мобильной ширины исправлены и включены в релиз v1.1.0.

## Скриншоты

Визуальные состояния панели на ширинах 390 px, 768 px и desktop проверены в ходе ручного прогона. Скриншоты проверки были показаны в рабочем чате; в репозитории они не приложены.
