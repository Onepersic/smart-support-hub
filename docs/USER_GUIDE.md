# Руководство пользователя

Smart Support Hub — учебная панель поддержки с вымышленными демонстрационными записями.

## Запуск
Откройте `index.html` через локальный HTTP-сервер, например Live Server в VS Code. Для графиков требуется CDN Chart.js.

## Инциденты
Откройте «Инциденты», нажмите «Добавить запись», заполните описание и приоритет. Фильтр находится на странице. Статус изменяется в строке таблицы. SLA: критический — 4 часа, высокий — 8, средний — 24, низкий — 72 часа.

## Заявки на изменения
В разделе «Заявки» создайте запись, выбрав один из четырёх видов сопровождения. Статус можно изменить в таблице. Данные отображаются на графике панели.

## Внедрения и релизы
Внедрения содержат заказчика, продукт, этап, готовность, владельца и дату. Релизы фиксируют версию, дату, уровень и изменения. Правило новой версии: patch меняет последнюю цифру, minor — среднюю, major — первую.

## Тема и данные
Кнопка ☼ переключает тему. Записи и тема сохраняются в localStorage текущего браузера. Очистите данные сайта в браузере, чтобы сбросить учебные данные.

## Поддержка
Для вопросов по учебному заданию обратитесь к преподавателю. Приложение не синхронизирует данные между браузерами.
