# Smart Support Hub

Учебная панель поддержки: внедрения, инциденты, SLA, заявки на изменения и релизы.

## Запуск
Запустите `index.html` через локальный HTTP-сервер (например, VS Code Live Server). Графики Chart.js загружаются с CDN.

## Страницы
Панель управления, внедрения, инциденты, заявки и история релизов. Данные вымышленные и сохраняются в localStorage браузера. Подробности — в [руководстве пользователя](docs/USER_GUIDE.md).
